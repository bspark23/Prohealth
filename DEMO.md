"PropHealth is revolutionizing healthcare in Africa by storing medical records securely on blockchain for less than 1 cent per record."

- Show modern healthcare design with blue gradient theme
- Highlight key features: Tamper-proof, AI-powered, Ultra-secure
- Point out "Each record costs less than $0.01"

### 2. Patient Portal Demo (2 minutes)

**Login:**

- Password: `demo123`

**AI Consultation:**
- Type: "I have a headache and feel tired"
- Show AI response with healthcare guidance
- Click "Store Record" button
- **Key Point**: "Watch as this consultation gets stored on Hedera blockchain"

**Medical Records:**
- Switch to "Medical Records" tab
- Show consultation with:
  - Symptoms extracted
  - AI summary
  - Blockchain transaction ID
  - Verification status

### 3. Doctor Portal Demo (1.5 minutes)

**Login:**
- Email: `doctor@demo.com`
- Password: `demo123`

**Access Patient Record:**
- Copy transaction ID from patient record
- Paste into "Patient's Transaction ID" field
- Click "Search"
- **Key Point**: "Doctor can now access patient's record using only the transaction ID"

**Add Medical Note:**
- Type: "Patient shows signs of stress-related headache. Recommend rest and hydration."
- Click "Add Doctor Note"
- **Key Point**: "This note is now permanently stored on blockchain and linked to the original consultation"

## 🚀 Judge Q&A Preparation

**Q: How does this scale to millions of users?**
A: Hedera can handle 10,000+ TPS with finality in 3-5 seconds. Our architecture supports horizontal scaling.

**Q: What about data privacy?**
A: Only metadata and hashes are stored on-chain. Sensitive data can be encrypted locally. Patients control access via transaction IDs.

**Q: How do you handle internet connectivity issues in Africa?**
A: The app works offline-first, syncing when connectivity is available. Critical data is cached locally.

**Q: What's the business model?**
A: Freemium model - basic records free, premium features for hospitals. Revenue from transaction fees and enterprise features.

**Q: How do you ensure regulatory compliance?**
A: Built with HIPAA-like principles. Blockchain provides audit trails required by regulators. Patient consent mechanisms built-in.
